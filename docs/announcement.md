# ChromoPlas — announcement templates (draft; publish only after GitHub prerelease exists)

## LinkedIn / research networks

Introducing **ChromoPlas v0.3.0 (public beta)** — an open-source Snakemake/Python workflow for visualizing antimicrobial-resistance and virulence signals in bacterial assembled genomes, together with predicted chromosome/plasmid compartments.

Starting from an assembled FASTA, ChromoPlas integrates ABRicate and MOB-suite, retains original contig coordinates and produces interpretable SVG maps, an HTML report and machine-readable tables. Ambiguous locations remain explicitly *unresolved*.

A real single-genome workflow completed end-to-end on Linux, and the Python/synthetic-integration tests passed. Wider platform testing and independent biological benchmarking are ongoing; predictions should not be treated as experimental confirmation.

**GitHub:** https://github.com/afsansarwer/ChromoPlas

**Documentation:** https://github.com/afsansarwer/ChromoPlas/blob/main/INSTALL.md

I welcome feedback, bug reports and reproducible test cases from microbiology and bioinformatics researchers.
